Status: Idle. Connect to WebSocket to begin.
Stage 1: Build Reference Panorama

Click Start, then slowly rotate the rig 360°. Watch the individual camera views below expand as they build their own panoramas. Click Stop when done.

Once stopped, process all captured frames into a single, high-quality reference panorama. This may take a few minutes and will appear in the main view below.

Stage 2: Calculate Camera Placements

Place the rig in its final, fixed position. Then capture one "anchor" frame from each camera.

Now, calculate the final placement of each camera relative to the reference panorama.

Stage 3: Final Stitched Output

The system is calibrated. Capture a new set of frames to stitch them into a final image using the calculated placements.
